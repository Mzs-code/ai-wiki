# AI 工程师（AI 技术基座与企业 AI 赋能）

> 工作地点：杭州｜对外招聘文本 v2.0

## 岗位职责

1. 搭建公司多产品核心知识库：与业务负责人共同评审内容，持续迭代，收口形成"金标准"。
2. 基于开源 agent 框架搭建公司 AI 技术基座：
   - agent 运行容器：runtime、沙箱、工具调用，支持弹性伸缩；
   - 知识库容器选型、历史版本管理、评测集建设；
   - 会话管理、运行观测、成本控制；
   - 模型管理、skills 平台、MCP 管理；
   - 对外 AI 网关：灰度发布、权限控制。
3. 基于 AI 基座赋能业务：
   - 落地企业核心业务流程 agent，如客服 agent、解决方案 agent、OA agent；
   - 打造数据飞轮：将钉钉/飞书/企微文档的增量内容经 agent 持续融入核心知识库（增量总结 agent → 人工审批 → 评审合并 agent）；
   - 基于 agent 会话与上下文，建设管理看板。
4. 管理公司 AI 大模型控制台，赋能并指导内部员工用好 AI：
   - AI 成本控制、识别 AI 先进使用者、"先富带动后富"、历史痛点改造（如 OA）的 ROI 评估；
   - 输出外部最新 AI 最佳实践（工具/提示词/skills/agent）、工程解法（agent 运行框架、知识库选型）与业务新玩法（AI 生图、PPT、表格处理等）。

## 任职要求

1. 偏后端技术出身，工作经验 5 年以上，有相对大体量公司的工程经验；
2. 工作地必须在杭州；
3. 深度使用 AI：有好奇心和主观能动性，持续跟进 AI 最新动态；
4. 有自己的 AI 方法论；使用过多种 AI、多种形态的 AI 产品，而非局限于单一平台或产品。

## 软性要求

1. 沟通能力强，性格偏外向；
2. 情商较高，有同理心；
3. 有耐心——这个岗位会持续面对初学者反复提问基础问题；
4. 写作能力好，能把复杂的技术内容写成业务同事看得懂的文档。
